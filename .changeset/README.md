# Changesets

Each change that consumers would notice adds a changeset: `pnpm changeset`, pick the bump, write one line in the past tense. The release workflow turns them into the version and CHANGELOG.

- **patch**: a fix that changes no API or look on purpose.
- **minor**: a new component, prop, token or class.
- **major**: a removed or renamed export, class or token, or a visual change apps must check.
