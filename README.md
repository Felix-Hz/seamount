<h1 align="center">seamount</h1>

<p align="center">A design system in CSS and React.</p>

| Package                                               | What it is                                                                   |
| ----------------------------------------------------- | ---------------------------------------------------------------------------- |
| [`@felix-hz/seamount`](packages/seamount)             | CSS, fonts, Tailwind 4 theme, and number and theme helpers. No dependencies. |
| [`@felix-hz/seamount-react`](packages/seamount-react) | React components and hooks, built on Radix.                                  |

Both are released together at the same version. Seamount is still 0.x, so pin the version.

To work on it, see [CONTRIBUTING.md](CONTRIBUTING.md). Licensed under [MIT](LICENSE).
